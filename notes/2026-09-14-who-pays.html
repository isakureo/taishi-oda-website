研究ノート補遺2026.09.14対外未提出・社内検討用

誰が請求書を
受け取るのか

08.26ノート「AIが速くなるほど、人間は遅い場所で稼ぐ」10案の、支払者の組み替え

前回の10案は「誰が価値を受け取るか」で設計した。受け取る人（高齢者、過疎地、個人作家、商店街）と払える人が一致していない案が多く、その穴を自治体予算で埋める前提になっていた。今回は支払者を先に決めてから事業を組み直す。10案の中身そのものは変えていない。変えたのは請求書の宛名だけだ。

自治体を外す理由は財源の善し悪しではない。単価が桁で足りず、年度で切れ、通った時点で「実証事業」として完了扱いになり、二度目の発注が構造的に来ないからだ。観光大使AIフェーズ0で確認したのは、ここだった。自治体は顧客から外し、後援名義と紹介を出す共同保証人として残す。

A

支払者を先に決める

同じサービスが、買う側の科目によって値段を変える。3日間の技能体験は、観光の科目で買われれば2万円、後継者教育の科目で買われれば50万円になる。原価は同じだ。10案の組み替えは全部この一点に集約される。

見送る理由
自治体の委託費は1件あたりの上限が低く、複数年契約になりにくい。単年度で成果報告書が出た時点で担当が代わり、関係が切れる。
構造の問題
公的予算は公平性で評価される。特定の1社・1人に集中投資して伸ばす、という事業の伸ばし方と評価軸が噛み合わない。
残す使い道
後援名義・現地の紹介・場所の貸し出しは、民間の支払者に売るときの信用を直接押し上げる。金は取らず、信用だけ借りる。

企業の既存科目

研修費 / 福利厚生費 / 周年・広報費 / 採用費

毎年必ず消化される予算。新規の稟議を起こさせるのではなく、すでに動いている科目の中に入り込む。

金融の付帯サービス費

保険の付帯 / 健保の保健事業 / 顧客維持費

解約を防ぐための費用。契約者が離れるコストと比べて判断されるので、効果の証明が単価より優先される。

ブランドと富裕層の体験費

外商 / ホテル体験仕入れ / 承継・子女教育

値引き交渉が最も弱い層。「他では買えない」ことが価格の根拠になり、身体性と本人保証がそのまま値札になる。

B

10案の組み替え

番号は08.26ノートと対応している。優先度ではない。各案は「支払者 / 予算科目 / 単価仮説 / フェーズ0の1件 / キル基準」の5項目でだけ書いた。これ以上の設計は、1件目の請求書が通ってからでないと意味がない。

01

熟練者レンタル基盤

自治体SaaS→高級宿の体験仕入れ

1泊10万円級の宿は「ここでしか買えない時間」で単価を守る必要があり、体験の仕入れ予算をすでに持っている。自治体に売るのは基盤利用料（数十万円・単年度）だが、宿に売るのは仕入れ原価で、埋まるかぎり毎月立つ。売るのは達人そのものではなく、名簿・保険・当日運営をまとめた供給網。

支払者ラグジュアリーホテル・高級旅館、法人インセンティブ旅行を組む旅行会社
予算科目宿泊商品の体験仕入れ原価 / MICE企画費
単価仮説1組 2〜5万円で宿が仕入れ、宿泊単価に上乗せ。取次手数料25〜30%＋名簿・保険の管理料。
フェーズ0（1件）1宿 × 1達人 × 10組を全部手配で回し、宿宛の請求書を通す。
キル基準宿が2回目を自発的に発注しない。または達人が3件目で降りる。
02

人力認証ラベル発行所

作家の年会費→混入リスクを負う側

個人作家は年会費を払えない。だが納品物にAI生成が混ざっていたと発覚したとき謝罪する側——広告主・出版社・ブランド——は払える。保険と同じ構造で、事故コストの一部を前払いさせる。自己申告では成立しないという性質も、第三者検査として売るほうに素直に乗る。

支払者広告主・広告代理店・出版社、高額工芸／アートの取引プラットフォーム
予算科目制作費内の校閲・検収費 / 真贋保証コスト
単価仮説1案件 3〜10万円の検査料、または取引額の1〜2%。
フェーズ0（1件）代理店1社の1案件で、納品ライターの制作過程を実際に検査し、報告書1枚を出して請求する。
キル基準出した報告書を法務・広報が読まない（＝事故コストとして認識されていない）。
03

職人ブランディング

工芸事業者の売上歩合→大企業の調達代行

ECを持てない工芸事業者に、制作費を出す体力はない。手仕事を欲しがっている側——周年記念品、株主優待、ホテルのアメニティ、外商の顧客ギフト——に予算がある。作り手から取るのをやめ、買い手から取って産地に流す調達代行に反転させる。作り手の言葉と手の跡は、納品物に付ける記録として一緒に売る。

支払者上場企業の周年事業事務局、百貨店外商、ホテル
予算科目周年事業費 / ノベルティ・ギフト調達費 / アメニティ費
単価仮説1案件 300〜2,000万円（調達＋撮影＋物語コンテンツ一式）。
フェーズ0（1件）1社の周年ギフト500個を、1産地だけで受注して納める。
キル基準発注元が「コピーはAI生成でいい」と言う（＝本人保証に値札が付いていない）。
04

対面リトリート設計

人事部の研修枠→投資先バリューアップ

研修市場は伸びているが、人事部の研修枠に入れられた瞬間に相見積りと単価比較の対象になる。同じ合宿を、PEファンドの投資先支援やIPO準備の組織づくりとして売ると、科目が経営課題になり桁が変わる。その場で組み替える判断力は、研修講師としてより、経営の場に立ち会う人として値付けされる。

支払者PEファンド（投資先支援）、IPO準備企業、創業家・資産管理会社
予算科目投資先バリューアップ予算 / 組織開発費
単価仮説1社 300〜800万円／回（設計・場所選定・当日ファシリ込み）。
フェーズ0（1件）1社の経営合宿を設計から当日まで担い、「何の意思決定が変わったか」を1枚で報告する。
キル基準次回も人事部の研修枠で処理される（＝経営課題として買われていない）。
05

高齢者伴走サブスク

高齢者本人の自己負担→介護離職を恐れる企業

訪問介護員の有効求人倍率14.14倍という穴は事実だが、穴の前に立っている高齢者本人に月額を払う習慣はない。払う動機が強いのは、遠距離介護中の社員を失いかけている企業と、契約者を引き止めたい保険・信託だ。社員1人の離職は採用と育成のやり直しになる。予防に金を出す理由がそこにある。

支払者大企業の人事・健保組合、生損保の契約者付帯サービス、信託・証券の富裕層顧客維持
予算科目福利厚生費 / EAP契約 / 付帯サービス費 / 顧客維持費
単価仮説全社契約で従業員1人あたり月100〜300円＋訪問実費。保険会社とは年間契約。
フェーズ0（1件）中堅1社の社員10名の親元へ、学生同行を3ヶ月。人事の離職リスク面談の変化を記録する。
キル基準人事が使ってほしい社員に使われない（＝制度として置かれただけで終わる）。
06

弟子入り合宿

観光パッケージ→後継者教育・私学

同じ3日が、観光の科目なら2万円、後継者教育の科目なら数十万円になる。オーナー家の事業承継、私立中高の探究学習、富裕層の子女教育は、どれも「体験の質」ではなく「その後の人格に効いたか」で買う。師匠との関係が体験後も続くという設計は、この科目でだけ正当に評価される。

支払者オーナー企業の創業家・資産管理会社、私立中高／インターナショナルスクール
予算科目後継者育成費 / 教育費
単価仮説1名 30〜80万円（3日・少人数・記録の納品付き）。
フェーズ0（1件）承継期のオーナー家1家族、親子2名で1本だけ組む。
キル基準終了3ヶ月後、師匠と1度も連絡が続いていない（＝観光と同じものを高く売っただけ）。
07

対面グループケア拠点

孤独・孤立対策予算→健保の保健事業費

孤独・孤立対策の予算は年度で増減し、採択されても単年で終わる。同じ場を、健康経営とメンタル対策の科目に置くと、健保組合の保健事業費という毎年必ず消化される予算に乗る。AI依存の自覚率が上がっているという事実は、ここでは市場規模ではなく、人事に説明するための導入理由として使う。

支払者企業の健康経営担当・健保組合、大学の学生支援部門
予算科目保健事業費 / EAP契約 / 学生支援費
単価仮説1セッション 10〜20万円、または1拠点あたりの年間契約。
フェーズ0（1件）1社1部署でピア・グループを8週。ストレスチェックの前後比較を取る。
キル基準2クール目を現場でなく人事が止める（＝効果を数字で示せていない）。
08

AI-Free連載レーベル

読者の直接購読料→広告主のブランド費

読者課金は積み上がるまでが長く、単価も薄い。先に払えるのは、AI量産記事に自社名を並べたくない広告主とオウンドメディアだ。売るのは文章そのものではなく、下書き・録音・改稿履歴という証跡を納品物に含めること。証跡の仕組みは02と同じものを使い、内製は1つに絞る。

支払者事業会社のオウンドメディア、ブランド、出版社の外注編集
予算科目コンテンツ制作費 / ブランド管理費
単価仮説記事1本 20〜60万円（証跡付き）。読者課金は3年目以降の任意。
フェーズ0（1件）ブランド1社に連載3本。証跡を納品物に必ず含めて出す。
キル基準発注元が「証跡は要らない」と言う（＝人が書いた保証に上乗せ価格が付かない）。
09

無人×有人ハイブリッド窓口

商店街の空き店舗→ビルオーナーと士業

空き店舗を抱えている商店街には、運営を委託する金がない。同じ仕組みを、共用部や空き区画の運営を外注したいビルオーナーに売り、常駐日の相談枠は士業の見込み客獲得費として売る。「この曜日にあの人がいる」という予測可能性は、来訪動機であると同時に、リードが読める営業チャネルでもある。

支払者不動産デベロッパー・ビルオーナー、社労士・行政書士・金融の営業部門
予算科目共用部運営費 / リーシング費 / 見込み客獲得費
単価仮説運営受託 月20〜50万円 ＋ 士業からのリード課金 1件1〜3万円。
フェーズ0（1件）1ビルの空き区画1つで、週2日だけ士業常駐を3ヶ月。リード数を数える。
キル基準無人日の稼働が賃料を割り、かつ士業がリードを買わない。
10

関係人口コーディネーター

自治体の下請け→地方に拠点を持つ企業

関係人口の予算は、受け取る側の自治体にはほとんどない。金があるのは出す側——企業版ふるさと納税の拠出企業、地方に工場や拠点を持ち地域対応を担当者1人に背負わせている企業、寄付者を引き止めたいポータル事業者だ。同じ人が何度も現れるという性質は、企業側では「担当が代わらない地域窓口」として売れる。

支払者企業版ふるさと納税の拠出企業、地方拠点を持つ事業会社、ふるさと納税ポータル・返礼品事業者
予算科目広報・地域共生費 / 寄付者リテンション費
単価仮説年間契約 300〜600万円／社。候補者の発掘はAI、継続接点だけ人力。
フェーズ0（1件）地方拠点を持つ企業1社の地域窓口を、半年だけ代行する。
キル基準先方の担当者交代で契約が消える（＝仕組みでなく個人の関係に乗っただけ）。
C

フェーズ0の規律

観光大使AIで学んだのは、仕組みを先に作ると、需要がなかったことに気づくのが半年遅れるということだった。10案すべてに同じ縛りをかける。

  1. 支払者を実名の1社で言えるまで着手しない。「企業の研修費」は支払者ではない。稟議を通す個人の顔と部署名まで書けて初めて着手する。
  2. 1件目は必ず手作業でやる。基盤化・SaaS化・テンプレ化は3件目以降。1件目で自動化したものは、だいたい誰も使わなかった。
  3. 値付けは原価からでなく、相手の科目から決める。同じ3日が2万円にも50万円にもなる。原価に利益率を乗せた瞬間、安いほうの科目に落ちる。
  4. 無料実証をやらない。請求書が通ったかどうかだけが需要の証拠。無料で喜ばれたという事実には、何の情報も入っていない。
  5. キル基準と期日を先に書く。上の10案には全部書いた。期日が来たら、手応えがあっても切る。
  6. 自治体は顧客から外し、信用の側に置く。後援名義・現地の紹介・場所。金を取らない代わりに、民間に売るときの信用として借りる。

数字の扱いについて

本ノートの単価・契約形態・料率はすべて設計上の仮説で、一次ソースはない。事実として確認済みなのは08.26ノートに引用した数値（訪問介護員の有効求人倍率14.14倍、統一ラベリング合意、企業向け研修市場5,858億円など）だけ。対外資料に転用する際は、この2つを必ず分けて書くこと。「孤独経済」「体験経済」の市場規模予測は出典間で100倍以上の開きがあるため、引き続き使わない。
